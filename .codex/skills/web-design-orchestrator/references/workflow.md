# Detailed workflow

## Gate 0 — Scope integrity
Confirm whether this is a new design, redesign, targeted component, or QA pass. Preserve user-owned code and existing constraints.

## Gate 1 — Design brief
Define business outcome, target users, primary job, information priority, conversion, content inventory, brand constraints, technical constraints and measurable CTQs.

## Gate 2 — Reference DNA
Separate what is admired into typography, composition, spatial rhythm, imagery, materiality, interaction and motion. State what will *not* be copied.

## Gate 3 — Art direction
Select a coherent POV, anti-direction, signature visual idea, signature interaction, visual-energy curve and responsive thesis.

## Gate 4 — System
Convert direction to tokens and rules. Any repeated visual decision should come from the system rather than accidental local values.

## Gate 5 — Build
Implement the core path semantically before enhancement. Add motion/creative layers only after the content flow works.

## Gate 6 — Recomposition
Test content priority, navigation and interaction at narrow widths. Simplify effects when they fight touch, space, battery or readability.

## Gate 7 — Visual and functional QA
Capture real screenshots, inspect overflow, console errors, keyboard use, reduced motion, image crop, loading and interaction states.

## Gate 8 — Independent critique
Score screenshots without relying on implementation intent. Identify high-leverage root causes.

## Gate 9 — Release
Web Design OS threshold + category floors + hard gates.

## Gate 10 — Learn
Convert recurring defects into proposed changes and regression scenarios.
