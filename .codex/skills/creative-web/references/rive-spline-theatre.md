# Rive / Spline / Theatre.js

## Rive
Best when a designer-authored vector asset needs interactive states and transitions. Keep the state machine aligned to actual UI state and provide nonanimated semantics outside the canvas.

## Spline
Best when a designer owns a 3D scene visually and the project benefits from direct web embedding or framework export. Audit scene complexity, materials, textures and interactions before shipping.

## Theatre.js
Best when artists/developers need editable timeline control over scene or DOM properties. When combined with GSAP/Lenis/R3F, prefer one coordinated frame driver where possible.
