# Design+Code / Meng To — distilled public-method lens

This reference is a synthesis of publicly described Design+Code course topics, not proprietary course material.

Use these questions during reference-to-interface work:

## Hierarchy before decoration
- What is the first, second and third read?
- Which element earns the largest scale?
- Does type, contrast and spacing tell the same hierarchy story?

## Design with systems, not screenshots
- Identify recurring primitives, variants and states.
- Separate a component's behavior from its current styling.
- Use tokens so polish can propagate consistently.

## Remix rather than clone
- Extract a useful idea from multiple references.
- Change the composition, content context, type system and interaction model to fit the current product.
- Keep the source's principle, not its identifiable arrangement.

## Polish loop
- fix hierarchy;
- fix spatial rhythm;
- fix typography metrics;
- fix imagery crop and material detail;
- add interaction feedback;
- add motion only where it creates continuity, focus or personality;
- recompose mobile separately.

## Design-to-code discipline
A visual idea is incomplete until it survives responsive behavior, real content, keyboard/touch interaction, loading/error states and performance constraints.
