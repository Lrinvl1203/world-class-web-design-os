# Component source catalog

## Accessible primitives
- Base UI — unstyled accessible primitives; strong when building a bespoke visual system.
- React Aria — accessible behaviors/components/hooks with robust interaction semantics.
- Radix Primitives — accessible low-level React primitives.
- shadcn/ui — owned source components useful as implementation substrate.

## Visual/animated registries
- 21st.dev — broad community React components/templates/effects and AI-oriented reuse.
- Aceternity UI — animated, high-visual-impact React/Tailwind patterns.
- React Bits — animated creative components plus background/shape/texture tools.
- Motion Primitives — reusable Motion-based interaction components.
- Magic UI — open-source animated components/effects for design engineers.
- Animate UI — animated React/TypeScript/Tailwind component distribution.

Use registries to accelerate capability discovery. Re-author their visual language into the project design system and verify current license/API before production use.
