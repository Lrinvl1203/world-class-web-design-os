# Release gates

## WCAG 2.2 AA examples to explicitly inspect
- 2.4.11 Focus Not Obscured (Minimum): keyboard-focused UI is not entirely hidden by author-created content.
- 2.5.7 Dragging Movements: provide a single-pointer non-drag alternative unless dragging is essential.
- 2.5.8 Target Size (Minimum): target is at least 24×24 CSS px or satisfies a valid spacing/equivalent/inline/user-agent/essential exception.

These are not the complete WCAG checklist.

## Core Web Vitals good targets
At the 75th percentile, target:
- LCP ≤ 2.5 s;
- INP ≤ 200 ms;
- CLS ≤ 0.1.

Use field data when available; lab measurements are diagnostic, not a substitute for field experience.
