# Anime.js notes

Use Anime.js when choreography is timeline-centric: staggered lists, letter/word sequences, SVG paths/properties, coordinated hero entrances, numeric/value animation or tightly controlled offsets.

Prefer a single readable timeline over scattered delays. Establish timing roles (lead, follow, settle) and avoid “domino” staggering on every list. Confirm current Anime.js API against primary documentation before implementation because major versions can change surface syntax.
