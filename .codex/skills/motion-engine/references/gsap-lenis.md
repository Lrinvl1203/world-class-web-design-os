# GSAP + Lenis notes

GSAP is the escalation path for sophisticated narrative motion: ScrollTrigger pin/scrub, complex sequencing, Flip layout transitions, text segmentation, MotionPath and synchronization with canvas/3D values.

Lenis is a scrolling layer, not a visual effect library. Add it only when scroll feel, inertia or synchronized scroll signal is central. When GSAP, Lenis and 3D run together, coordinate their update timing and test low-power mobile devices.
