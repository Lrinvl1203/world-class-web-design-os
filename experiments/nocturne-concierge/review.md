# WDX Review — Nocturne 24

**WDX:** 89.4 / 100  
**Internal release threshold:** 92  
**Decision:** HOLD

## Why it is strong

The first experiment successfully escaped generic AI/SaaS composition. It has a coherent quiet-editorial hospitality point of view, an intentional page energy curve, authored mobile recomposition, restrained native motion, useful guide state changes, and a keyboard-dismissable Today panel.

## Why it does not get 92+

1. **Imagery specificity:** the abstract CSS city/window language is coherent but cannot substitute for a proprietary spatial/photographic asset system in an exceptional hospitality site.
2. **Signature behavior:** the guide interaction is useful, but the site still lacks one unmistakable task-linked interaction that users would remember as *Nocturne* behavior.
3. **Micro legibility:** several micro labels are intentionally small. They work in the captured layouts, but production approval requires real-device inspection and real content-length stress tests.

## Automated evidence

Browser smoke checks passed at 320×568, 375×812, 390×844, 768×1024, 1440×900 and 1920×1080 with:

- no horizontal overflow;
- no console errors;
- working guide state change;
- Today panel open + Escape close;
- zero dead `href="#"` links;
- reduced-motion mode showing content immediately and disabling smooth scroll.

Core Web Vitals field thresholds are **not claimed as measured** because the experiment has not been deployed to a representative URL/field population.

## Learning signal

This is a useful failure: visual quality can reach “premium” while remaining below the OS's 92 release line. The countermeasure is not “add more effects”; it is stronger place-specific imagery, one meaningful signature interaction, and production-device/field validation.
