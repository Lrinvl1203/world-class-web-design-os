Reading / what survives

Every copy
authors again.

“Reproduction does not merely lower fidelity. It produces a new public, a new distance, and a new kind of urgency.”

The useful question is not whether the fifth edition is authentic. It is whether we can see the decisions that made it different. Cropping removes a place. Translation changes who can answer. Compression turns a wall-sized request into something held in one hand.

This interface keeps those edits beside the object. The image moves; the evidence does not disappear.
