# Project brief — Afterimage Atlas

- Status: fictional public design study; no affiliation with a real museum or archive.
- Goal: help a curious visitor understand how one protest poster changes meaning as it is copied, cropped, translated, and recirculated.
- Audience: culture readers, students, researchers, and mobile visitors arriving from a shared link.
- Primary job: follow a coherent object story without needing specialist archival knowledge.
- Primary action: move through five annotated states of the same object.
- Content priority: thesis → object → transformations → annotation → provenance.
- Brand: rigorous, humane, tactile, quietly confrontational.
- Anti-direction: museum beige, masonry gallery, card catalogue nostalgia, cinematic loading screen, decorative parallax.
- Signature idea: the page behaves like an illuminated contact sheet; selecting an edition moves the reading aperture and rewrites the margin note.
- Constraints: no external fonts, imagery, libraries, tracking, or network requests; all essential content remains available without JavaScript.
- CTQs: Can a first-time visitor state what changed? Can they identify the active edition without relying on motion or color? Does the reading order remain intentional at 320 px?

## Reference principles

- Editorial chaptering and visible index, extracted from cultural/editorial patterns in the repository reference atlas.
- Object-led navigation: the interaction verb is “inspect,” not “scroll for spectacle.”
- Presence over volume: one dominant object, restrained motion, explicit provenance.
