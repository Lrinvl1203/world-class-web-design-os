03 / PUBLIC METHOD

What the field shows +

A procedural 7 × 6 block grid. Height is a normalized cooling benefit; color is an illustrative surface temperature. The adjacent table contains the same comparison without canvas.

What it does not claim +

No measurements, forecasts, addresses, or demographic records are used. This case study demonstrates interface behavior only and must not be used for planning decisions.

How it stays light +

No 3D library or asset download. Rendering uses one Canvas 2D context, capped device pixel ratio, fewer cells on narrow screens, and no perpetual loop.
