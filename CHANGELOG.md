# Changelog

All notable changes to WDX are documented here. The project follows [Semantic Versioning](https://semver.org/) from the first public release.

## [Unreleased]

- Public launch readiness checks and external field evaluation.

## [0.2.0] - 2026-08-10

- Added a proof-led launch site and social preview.
- Added one-line GitHub installation and `wdx doctor` verification.
- Added complete package metadata and a package smoke-test path.
- Added open-source contribution, security, conduct, issue, and release documents.
- Added GitHub Pages deployment workflow and launch-site browser gates.
- Clarified internal WDX scores versus field evidence.

## [0.1.0] - 2026-08-08

- Added the 17-skill web-design operating system.
- Added a 100-reference evidence atlas and controlled daily learning pipeline.
- Added Nocturne Concierge and VANTA Forge verification experiments.
