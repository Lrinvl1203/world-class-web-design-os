# 40-Reference Design Study — WDX Knowledge Upgrade

This document records the second research pass used to strengthen the World-Class Web Design OS. The reusable operational version lives at `.codex/skills/reference-forensics/references/award-pattern-atlas.md`.

## Research design

The study deliberately mixes two evidence types:

- **case studies/demos** where implementation intent is documented (strong evidence);
- **award benchmarks** that establish relevance but require screenshot/runtime inspection before a specific mechanic is attributed to them.

This prevents a common failure mode: inventing design lessons from an award title without examining the work.

## What changed in the OS

1. Added an explicit 40-reference pattern atlas.
2. Added evidence grades A/B/C so Codex knows how confidently it may infer mechanics.
3. Added the principle `content and interaction must share a verb`.
4. Added `presence, not volume` as a motion/composition check.
5. Added tool-selection guidance from current Motion/Anime/Three/Rive documentation.
6. Strengthened mobile-specific motion routing and GPU progressive-enhancement rules.
7. Added a provenance requirement: a reusable rule needs documented evidence or repeated project evidence before entering the core OS.

## Main cross-reference findings

### Meaning-driven signatures outperform effect collections
A recognizable project usually has one governing metaphor or material logic. Signature interaction should be derived from that concept, then supported by smaller behaviors.

### Editorial composition remains a powerful differentiator
Controlled negative space, strong type roles, crop logic, rhythm, asymmetry and selective visual intensity often produce more durable distinctiveness than trend-heavy decorative effects.

### Creative engineering should be progressive
The strongest technical case studies explicitly discuss performance, selective rendering, mobile behavior, fallbacks or tool intentionality. Creative technology therefore belongs inside the quality system, not outside it.

### Motion should carry continuity, hierarchy or narrative
A site is not more premium because more things move. Motion earns its place when it explains state, preserves spatial continuity, controls attention, creates narrative pacing or expresses a brand-specific physical metaphor.
