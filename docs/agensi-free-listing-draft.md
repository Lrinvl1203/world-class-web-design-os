**Title:** Web Design OS — Free Starter Bundle

**Price:** Free

**Short description:** One reusable web-design workflow with 17 routed agent skills, a local CLI, design references, a transparent critique rubric, and browser QA starters.

**Description:**

Bring a structured design-and-review workflow to an existing web project. Start with the orchestrator, then load relevant specialists for discovery, art direction, design systems, implementation, responsive composition, accessibility, critique, and visual QA.

This single download includes the 17 skills and their references, shared CLI and configuration, a critique rubric, screenshot and browser-test starters, existing fictional example sites, installation instructions, and the original MIT license and provenance notices. The bundled installer copies companion resources as well as skill files, so the installed CLI can run without a source-repository checkout. Doctor checks installed file integrity; it does not grade a generated design.

Use the local route and reference-search commands to explore the workflow, create a project-context template, and reproduce the included Sequence Desk example. Browser checks require separately installed Playwright dependencies and Chromium. The installer and basic CLI commands need Node.js 20+ and no API key. Optional agent services and integrations have their own requirements and costs.

**Compatibility:** Declared skill-directory layouts for Codex, Claude Code, Cursor, GitHub Copilot, OpenCode, and the shared `.agents/skills` convention. Local installation layouts are tested; host-specific discovery and agent behavior are not certified across all products. Agensi import itself has not been tested.

**Evidence and limitations:** Local verification covers ZIP extraction, isolated installation, companion-file access, CLI smoke checks, and the existing-example reproduction. These checks do not establish new agent design performance, independent-user effectiveness, field Core Web Vitals, conversion improvement, revenue, or a guaranteed “world-class” result. The repository's historical example scores are internal rubric declarations.
