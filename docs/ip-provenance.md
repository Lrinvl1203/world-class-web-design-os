## Name-collision corrections

The initial short public label was retired after current web searches found established web-design businesses and a design community using the same acronym. The project now uses the descriptive full name **World-Class Web Design OS**, while the executable is `web-design-os`.

The industrial demonstration was renamed **Linehold Forge** after an exact current use of its former name was found online. The rename reduces avoidable source-confusion risk; it is not a formal trademark opinion.

## AI-assisted material

OpenAI's terms state that, as between the user and OpenAI and to the extent permitted by law, the user owns output, while also warning that output may not be unique and must be reviewed before sharing. Separate copyright law may protect human-authored selection, arrangement, and modifications without necessarily protecting purely AI-generated elements. The repository therefore does not claim exclusivity over the underlying synthetic image content.

## Remaining risk controls

- Do not present linked companies, tools, communities, or awards as sponsors or partners.
- Do not copy source articles, paid lessons, reference screenshots, logos, templates, or site code into the repository.
- Replace synthetic images and fictional operational claims before adapting either experiment for a real client.
- Review contributor submissions for provenance, license compatibility, secrets, and brand confusion.
- Run a jurisdiction-specific trademark clearance before commercializing a standalone branded product or paid service.
- Preserve third-party license notices if dependencies or example code are ever vendored or redistributed.
